# Local Tourist Day-Visit Planner and Information System (Mattegoda)

ITE2953 Programming Group Project - University of Moratuwa (BIT)
Developer: J A S R Perera (E2410994)

A web application that helps visitors discover places of interest within 25 km of
Salgas Junction, Mattegoda, and build a one-day visit plan with map routing and a time budget.

## Tech stack
HTML, CSS, Bootstrap 5, JavaScript, Leaflet.js + OpenStreetMap, OSRM · PHP 8 · MariaDB/MySQL · Apache (XAMPP)
